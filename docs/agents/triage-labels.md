# Triage roles

For the local tracker, these names are values of a ticket's `Status:` field.
They are not labels that need to be created on a remote server.

| Skill role | Local value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the task |
| needs-info | needs-info | Requirements or evidence are missing |
| ready-for-agent | ready-for-agent | Scope is specified and approved for an agent |
| ready-for-human | ready-for-human | Human action or decision is required |
| wontfix | wontfix | The task will not be implemented |

Execution states and dependency completion are defined in `issue-tracker.md`.
